# Website SDN 19 Rambah Lanai

Website resmi SDN 19 Rambah Lanai, Kec. Padang Gelugur, Kab. Pasaman.

🌐 Alamat website: https://sdn19rambahlanai.github.io/sdn19rl/

## Isi folder
- `index.html` : isi seluruh halaman website
- `script.js`  : memasang foto, galeri, dan testimoni
- `images/`    : semua foto website

## Cara memperbarui

**Menambah foto galeri**
1. Unggah foto ke folder `images` (nama file tanpa spasi dan tanda petik, ukuran di bawah 300 KB).
2. Tambahkan nama file di daftar `galeri` pada `script.js`.
3. Urutan di daftar harus sama dengan urutan kotak galeri di `index.html`.

**Mengganti berita dan pengumuman**
Edit bagian `Berita & Pengumuman` di `index.html`. Tulis bulan dan tahun kegiatan, dan hapus
pengumuman yang sudah lewat.

**Mengisi testimoni wali murid**
Tambahkan baris di daftar `TESTIMONI` pada `script.js`. Bagian "Kata Wali Murid" akan tampil
otomatis setelah ada isinya. Hanya untuk testimoni asli dari wali murid yang sudah mengizinkan.
Cukup nama depan dan kelas, tanpa nama anak.

## Catatan
- Setelah mengubah file, tunggu 1–3 menit, lalu buka website dan tekan Ctrl+F5.
- Jangan menyimpan kata sandi atau data pribadi murid dan guru di repo ini.
